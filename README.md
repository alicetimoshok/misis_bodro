# ☕ Бодро кофе — предзаказ ко времени и подбор напитка

Демо-приложение для сети кофеен «Бодро кофе» (Python + Streamlit).

## Проблема

- В часы пик у кофеен возникают очереди: клиенты теряют время, бариста работает рывками, часть гостей уходит.
- Гость не всегда знает, что выбрать из большого меню, и берёт «как обычно» или уходит без заказа.

## Решение

1. **Заказ ко времени.** Клиент собирает заказ и выбирает слот получения (шаг 10 минут). На каждый слот действует лимит заказов, поэтому нагрузка равномерно распределяется, а напиток готов к приходу гостя.
2. **Подбор напитка по опросу.** 6 коротких вопросов (настроение, температура, крепость, сладость, молоко, закуска) → 3 лучших напитка с процентом совпадения, объяснением «почему» и предложением закуски в пару.
3. **Бариста и аналитика.** Очередь заказов по времени получения со сменой статусов и сводка по выручке, среднему чеку, популярным позициям и загрузке по часам.

## Функции

| Раздел | Что делает |
| --- | --- |
| Меню | Категории, карточки, корзина, выбор слота, имя/телефон/комментарий, демо-оплата |
| Подбор напитка | Опрос, рекомендации с процентом совпадения, закуска в пару, добавление в заказ |
| Мои заказы | Заказы текущей сессии и поиск по телефону, отмена принятого заказа |
| Для баристы | Очередь по времени, статусы «Принят → Готовится → Готов → Выдан» |
| Аналитика | Метрики и графики по демо-данным |

Проверка ввода: имя, телефон (нормализуется к `+7XXXXXXXXXX`), длина комментария, лимит 10 шт. одной позиции, время работы 08:00–22:00, минимум 10 минут до получения, не дальше 2 дней, лимит 4 заказа на слот, допустимые переходы статусов. Повреждённый файл заказов не роняет приложение.

## Технологии

Python 3.10+, Streamlit, pandas, pytest. Данные хранятся в JSON-файле `runtime_data/orders.json` (создаётся при первом запуске с демо-заказами).

## Структура

```
app.py          интерфейс Streamlit
logic.py        бизнес-логика (корзина, слоты, валидация, заказы, подбор, аналитика)
menu_data.py    меню, вопросы опроса, генератор демо-заказов
styles.py       CSS и HTML-блоки в стиле референса
tests/          unit-тесты логики и смоук-тест интерфейса
.streamlit/     тема оформления
```

## Запуск

```bash
python -m venv .venv
# Windows:   .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на http://localhost:8501.

## Тесты

```bash
pytest -v
```

## Ограничения демо и идеи развития

- Нет авторизации (раздел баристы открыт), оплата имитируется.
- Выбор города и точки не влияет на заказ; в продакшене слоты считаются по точкам.
- Вместо JSON — база данных (PostgreSQL), уведомления клиенту о готовности, интеграция с кассой.
- Вместо эмодзи в карточках — фотографии продуктов.

## Сценарий демонстрации

1. Меню → добавить капучино и круассан → выбрать слот → ввести имя и телефон → «Оформить предзаказ».
2. Подбор напитка → пройти опрос → добавить рекомендацию в заказ.
3. Мои заказы → увидеть заказ, отменить его.
4. Для баристы → перевести заказ в «Готовится» → «Готово» → «Выдать».
5. Аналитика → показать пики загрузки.
